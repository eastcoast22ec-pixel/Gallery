Render Billing Engine V4

Render Billing Engine V4 is a private operational utility used by its owner to monitor Render usage state and maintain a controlled Google Apps Script workflow.

Purpose

  • Track and classify Render usage and service state.
  • Maintain a controlled Apps Script source-synchronization workflow.
  • Use Google OAuth only for permissions explicitly shown on the Google consent screen.

Data handling

The application is intended for the owner's own account and operational data. It does not sell Google user data or use it for advertising.
